# FS25_gameplay RoadMaster

The RoadMaster mod is a highly useful extension for Farming Simulator 25, providing a wide range of relevant data and features for detailed vehicle monitoring.</br>
Information such as distance traveled, fuel consumption, engine temperature, RPM, average speed, and range significantly enhance the gameplay experience.</br>
Additionally, they enable more efficient vehicle handling and optimized operation.</br>
All features and settings are easily and quickly accessible in-game, allowing users to conveniently customize the displayed information according to their preferences.</br>
</br>
For full functionality of the mod, the use of the Vehicle Years add-on (FS25_Vehicle_Years - by Thalley) is recommended, as its presence provides an enhanced experience,
including additional sound effects when switching HUD displays, making the RoadMaster features even more immersive.
</br></br>
Open RoadMaster (RM): "Left Ctrl + n" key combination</br>
Switch display: "-" (KEY_minus) key</br>
Reset trip counter: Hold "-" (KEY_minus) for 1.5 seconds</br>
